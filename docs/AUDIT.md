# Wind Blog 审计与修复记录

审计日期：2026-10-14。范围：服务端与页面鉴权、初始化、文章与评论访问、上传与清理、数据库查询与事务、前端写作流程、迁移脚本、依赖和生产构建。以下问题均已在当前工作区修复。

## 安全

| 问题 | 修复 |
| --- | --- |
| 未配置 JWT 时使用公开固定密钥，可伪造站长身份 | 生产环境要求随机密钥且拒绝示例占位值；开发环境生成进程随机密钥；限制 HS256 和整数用户 ID |
| 服务端页面信任 JWT 内旧权限，改密码后旧令牌仍有效 | 页面和 API 共用数据库校验；签名令牌绑定当前密码指纹，改密码后立即失效 |
| 浏览器把 JWT 长期保存在 localStorage | 改用 HttpOnly 登录 Cookie，移除旧存储副本；插件仍可使用 Bearer JWT |
| 登录 Cookie 缺少 HTTPS Secure，写请求缺少跨站校验 | HTTPS 下设置 Secure；拒绝来自其他源的浏览器写请求 |
| 登录与文章密码可无限尝试，同步 bcrypt 阻塞请求 | SQLite 持久化账户、文章和全站限流；公开密码验证改用异步 bcrypt |
| 密码文章自动摘要、封面及摘要搜索会泄露受保护内容 | 未解锁不返回正文、摘要、封面；访客搜索不匹配密码文章摘要 |
| 私密和待审核文章可经评论接口访问，解锁接口可旁路审核规则 | 页面、详情和评论共用可见性规则；评论读取、创建及点赞要求文章可读 |
| 修改文章密码后旧解锁令牌仍有效，签名比较及格式检查不严 | 令牌绑定密码摘要、严格分段并恒定时间比较签名 |
| 文章密码超过 bcrypt 72 字节截断后可出现等效密码 | 写入与验证均限制 72 字节；创建和更新使用一致的空白处理 |
| 轻量 Markdown 预览执行原始 HTML，社交链接允许危险协议 | 轻量预览禁用 HTML；社交链接按协议过滤，完整 Markdown 保持原有消毒流程 |
| JSON / multipart 未限制请求体大小，错误 JSON 被当作空对象 | 按流读取并限制大小；畸形 JSON 与非对象返回 400，超限返回 413 |
| 图片只信任 MIME，SVG 字符串黑名单遗漏事件处理器等 | 校验位图签名和 10MB 上限；拒绝主动内容 SVG |
| ZIP 只限制压缩大小，可发生解压资源耗尽及路径问题 | 解压前校验声明大小、展开预算、文件数和路径；拒绝绝对、反斜杠、点段及编码路径 |
| Next 图片优化接口允许任意远程域名 | 移除未使用的通配远程域名配置，避免公开代理任意远程图片 |
| 旧博客链接转发直接拼接解码路径段 | 对路径段编码，阻止生成跨域跳转目标 |
| 默认 seed 密码公开，seed 可在已初始化站点添加站长 | seed 仅限空站，要求显式提供至少 12 字符密码；初始化事务内再次校验 |
| 依赖扫描有 7 项告警 | 更新 Next 15、KaTeX、Mermaid、Vitest；覆盖 PostCSS 到补丁版本；最终 npm audit 为 0 |

依赖补丁依据：维护者的 [Vitest 安全公告](https://github.com/vitest-dev/vitest/security/advisories/GHSA-82fw-gwwq-j7x9) 和 [PostCSS 安全公告](https://github.com/postcss/postcss/security/advisories/GHSA-fxqj-rqcc-2cmp)，以及 npm audit 的依赖树扫描。扫描结果只代表当时公布的依赖告警。

## 操作逻辑与功能

| 问题 | 修复 |
| --- | --- |
| setup / register 在读取请求体前检查空站，并发请求可创建两个账户 | BEGIN IMMEDIATE 事务内重新检查，并把用户、开通与初始设置作为原子操作 |
| 前台解锁成功后刷新仍然锁定，返回的解锁文章缺少完整作者信息 | 设置两小时 HttpOnly 解锁 Cookie，SSR 与评论接口识别；解锁读取完整关联文章行 |
| 局部更新文章未传分类却重置为默认分类，手工摘要与 recommend 被忽略 | 区分未传字段与明确清空；保存手工摘要和精选字段 |
| 文章与标签、点赞计数、评论删除计数等多步更新可半途落库 | 使用事务，支持嵌套 savepoint；验证失败完整回滚 |
| 置顶重排可传重复 ID，私密文章仍占置顶集合 | 验证集合唯一性；转私密时清除置顶，拒绝私密文章置顶 |
| 页面参数未经转换，字符串 false 被保存为 true | 显式转换页面参数，保留局部更新语义 |
| ZIP 单目录导出找不到 index.html，失败替换会覆盖线上文件 | 支持统一外层目录；新目录上传成功后切换；失败清理已上传文件并保留当前版本 |
| 静态站点重新上传会重置导航设置 | 未传导航字段时保留已有值；限制为四个并发上传，失败后等待本批结果再清理 |
| 图片清理仅检查文章，可误删页面、主题固定页及头像图片；远端删除失败仍删除记录 | 共用引用 SQL 检查所有内容类型；远端失败保留记录供重试 |
| 自定义页保存失败也清空草稿，点赞按钮允许并行重复提交 | 仅成功后清空草稿；点赞请求期间禁用按钮 |
| 迁移 keep 模式无法在新站恢复源文章密码，导致文章迁移失败 | 仅保留已有目标密码；否则转为私密并明确提示，同时保留摘要和精选字段 |
| 自动化 seed / schema 命令未读取 README 约定的环境文件 | 命令显式读取 .env.local；同步修正 README 的路径、授权与限制说明 |

## 性能

- 将代码复制所需的纯 DOM 文本提取函数从完整 Markdown 库拆出，避免读者页面携带语法高亮、DOM 解析和公式渲染代码。
- 文章 HTML 在服务端生成；搜索摘要与编辑器预览按需加载，保留代码复制和 Mermaid 功能。
- 生产构建的 First Load JS：首页约 **613 → 117 kB**；文章页约 **633 → 137 kB**；编辑器约 **663 → 167 kB**。这反映构建输出的包大小，未经浏览器计时或网络压测。
- 评论先在 SQLite 分页根节点，再递归读取当前页回复；删除子树改为递归查询，减少逐条往返。
- 列表不再读取整篇正文、密码哈希和图片哈希；图片清理在 SQL 分页并共用引用表达式；正文图片哈希查询按批处理。
- 分页统一为有界整数，消除小数 LIMIT/OFFSET 的 SQLite 错误；限制公开标签查询数量。
- 添加文章公开列表和评论父节点索引，schema 仍为唯一幂等真源。

## 部署变化与边界

- 升级前的 JWT 没有密码指纹，需重新登录；文章旧解锁令牌也需重新解锁。
- 本地已有 JWT 配置通过长度和占位值校验，未修改实际凭据。配置 NEXT_PUBLIC_SITE_URL 时应使用真实访问源；未配置则使用请求源校验。
- 解锁和登录限流以固定时间窗口计数，达到限制后等待窗口过期。当前保护不替代部署层连接数、请求超时或网络流量限制。
- 又拍云静态站点旧版本文件仍保留。删除数据库记录不会自动回收旧云文件，需要结合存储策略清理；当前修复确保失败上传不会替换线上版本。
- 未执行真实云存储集成测试、浏览器视觉测试、长时间负载测试或外部渗透测试。本次结论以代码检查、回归测试、构建及生产 HTTP 冒烟为依据。
