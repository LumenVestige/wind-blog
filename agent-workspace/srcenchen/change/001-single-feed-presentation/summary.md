# 单列首页展示调整

单列首页使用更大的卡片、标题和间距，桌面有图卡片右侧为通高封面，图片边缘向文字区域渐隐。文字保留独立区域，无图卡片文字全宽。手机有图卡片改为上图下文，图片下缘渐隐，适配深浅色及悬停背景。

后续按用户反馈收紧尺寸：桌面卡片最小高度由 15rem 调到 13.5rem，封面宽度由 43% 调到 40.6%，默认高度下封面面积约减少 15%；同时缩小纵向内边距和内容间距。手机封面高度由 12rem 调到 10.2rem，面积减少 15%，无图卡片最小高度调到 12rem。

单列默认每页 6 篇，双列仍为 12 篇。SSR 和 JSON 共用同一次布局读取及页大小计算，分页链接按布局默认值省略 pageSize，显式设置原有合法页大小仍有效。双列卡片、侧栏和文章页排版保持原样，无 schema 或插件接口变更。
