# 单列首页大图卡片与分页：变更方案

关联：[spec.md](spec.md)

## 方案概述

单列卡片单独渲染右侧大图，双列继续使用摘要旁缩略图。使用 CSS mask 渐隐图片边缘，使深浅色及悬停背景自然透出；有图时限制文字区域，无图保持全宽。单列提高卡片高度、标题字号、内边距与卡片间距；窄屏采用上图下文。

共享首页默认页大小函数，单列为 6、双列为 12。首页加载一次布局并同时用于页大小与响应字段，单列额外允许 pageSize=6，原合法显式页大小继续支持。分页组件接收本布局默认大小，生成链接时省略默认 pageSize，无需 schema 迁移；回退后仍使用旧默认值。

## 改动范围

- 展示：`blog-page-view.tsx` 的单列头图位置及 `blog-mizuki.css` 的单列大卡片、渐变、响应式样式。
- 分页：`lib/pagination.ts`、`server/blog/page-data.ts`、`blog-pagination.tsx`；默认分页随已保存布局读取。
- 文档：README、SDD、Note。
- 接口：现有 `/api/blog/page` 首页数据的单列默认 pageSize 从 12 变为 6，信封及其余字段不变；不修改插件接口。
- 验证：按用户要求不运行测试、浏览器验证或构建；静态检查变更并如实说明未验证范围。
